# Day 1 – Introduction to Agentic AI and Groq API

## Overview
This task introduces the basics of building AI-powered chatbots using Python, LangChain, and the Groq API.

As part of this task, I developed a simple chatbot for **Sweet Crumbs Home Bakery** that responds to customer queries based on predefined instructions.

## Objectives
- Understand how to connect Python applications with the Groq API.
- Learn the basics of LangChain and the `ChatGroq` model.
- Create a chatbot using system and user prompts.
- Understand how an AI model generates responses.
- Explore basic prompt safety checking using Groq's Prompt Guard model.

## Technologies Used
- Python
- Google Colab
- Groq API
- LangChain
- `langchain_groq`
- Groq Prompt Guard

## Key Features
- Answers customer questions about bakery services.
- Provides information about eggless cake options.
- Follows the 24-hour advance-order requirement.
- Avoids making unsupported delivery-time promises.
- Generates short and friendly responses.
- Includes a basic prompt safety-checking example.

## How to Run
1. Open the notebook in Google Colab.
2. Install the required Python package.
3. Add your Groq API key to Google Colab Secrets using the name `GROQ_API_KEY`.
4. Run the notebook cells sequentially.
5. Test the chatbot with different customer questions.

## Learning Outcome
Through this task, I learned how to use the Groq API with Python, create prompts, initialize an AI chatbot using LangChain, and generate responses based on predefined instructions.
